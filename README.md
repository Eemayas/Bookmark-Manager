# Project Overview
Bookmark Manager is a Progressive Web App (PWA) designed to help you manage your bookmarks efficiently across devices. Whether you're browsing on a desktop, tablet, or mobile device, this app ensures your bookmarks are accessible and well-organized. With features like cloud storage, powerful search capabilities, and a user-friendly interface, Bookmark Manager provides a seamless experience for users to save, categorize, and retrieve their favorite web links anytime, anywhere.

# Key Features
- **Cross-platform accessibility**: Access your bookmarks from any device, regardless of operating system or browser.  
- **Cloud storage**: Save and sync your bookmarks securely in the cloud.  
- **Search functionality**: Quickly find bookmarks with an efficient search feature.  
- **User-friendly interface**: Manage your bookmarks with an intuitive and easy-to-use design.  
- **Progressive Web App (PWA)**: Install the app on your device for offline access and a native-like experience.

# Getting Started

Before starting the installation process, ensure you have a basic understanding of JavaScript, Node.js, and Git.

**Prerequisites**

1. **Node.js**: Install the latest version of Node.js from the official website: <https://nodejs.org/en/download/>
2. **Git**: Install Git from the official website: <https://git-scm.com/downloads>
3. **Docker**: Install Docker Community Edition (CE) from the official website: <https://www.docker.com/community-edition>
4. **npm**: Ensure that npm is installed and up-to-date by running `npm install -g npm@latest`
5. **yarn**: Optional, but recommended for this project. Install yarn using `npm install -g yarn`

## Installation

1. **Clone the Repository**: Clone the Bookmark-Manager repository from GitHub using Git:
```bash
git clone https://github.com/Eemayas/Bookmark-Manager.git
```
2. **Change into the Project Directory**: Navigate to the project directory using the command:
```bash
cd Bookmark-Manager
```
3. **Install Dependencies**: Install the required dependencies using npm or yarn:
```bash
npm install
# or
yarn install
```
4. **Set Environment Variables**: Create a `.env` file in the root directory and add the necessary environment variables:
```makefile
# .env
REACT_APP_API_URL='http://localhost:3001/api'
REACT_APP_PUBLIC_PATH='/'
```
5. **Configure Docker (Optional)**: If you choose to use Docker, configure it by running:
```bash
docker-compose up --build
```
## Running the Project

1. **Start the Server**: Start the server using npm or yarn:
```bash
npm start
# or
yarn start
```
2. **Open in Browser**: Open your web browser and navigate to `http://localhost:3000`

## Troubleshooting

1. **Missing Dependencies**: Ensure that all dependencies are installed correctly by running `npm install` or `yarn install`.
2. **Environment Variables**: Check the `.env` file for any mistakes or missing variables.
3. **Docker Issues**: If using Docker, ensure that it is installed and configured properly.

### Contributing Guidelines

1. **Fork the Repository**:
    - Start by forking the project repository to your GitHub account.
2. **Clone the Repository**:
    - Clone your forked repository to your local machine using the command:
    ```sh
    git clone https://github.com/your-username/Bookmark-Manager.git
    ```
    - Replace ``your-username`` with your GitHub username.
3. **Create a New Branch**:
    - Create a new branch for your changes using the command:
    ```sh
    git checkout -b your-branch-name
    ```
4. **Make Your Changes**:
    - Edit, add, or delete files as needed. Ensure your changes align with the project's contribution guidelines.
5. **Commit Your Changes**:
    - Stage your changes and commit them with a descriptive message:
      ```bash
      git add .
      git commit -m "Your descriptive message"
      ```
6. **Push Your Changes:**
    - Push your branch to your forked repository:
      ```bash
      git push origin your-branch-name
      ```
7. **Create a Pull Request (PR):**
    - Go to the original repository on GitHub and click “Compare & pull request.” Provide a clear description of the changes and submit the PR.

Once your PR is reviewed and approved, it will be merged into the main branch.
